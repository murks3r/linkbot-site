# Truth check: every claim on the site, what backs it, when it was last checked

Every page that goes live is re-read on the day it goes live against what the product does that day (owner, 2026-10-23), and only then merged to `main` with the owner's go. This list is the tool for that: one row per claim, the fact that backs it, the date it was last checked, and a mark where the sentence depends on work that is not finished (so the go-live check finds it).

The words themselves live in `src/i18n/en.ts` (the source) and the other catalogues; every language says the same thing, so a row covers all five. "Where" names the catalogue key.

**Sources.** `C` = the Space API contract 0.2.7 (`contracts/space-api/openapi.yaml` in murks3r/linkbot; its info text has the invariants, the matching, approval, introduction, mail and deletion paragraphs, the owner-token and language rules). `D` = the Connect lane's docs in murks3r/linkbot-connect (`docs/…`). `L` = a Linear decision. `R` = this repository. A row marked **unfinished** states something true today that another lane's work will change (a route that answers "not implemented", a package not published, a slice being built).

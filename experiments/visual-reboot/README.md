# Linkbot — visual reboot (prototype)

An isolated, **dependency-free** visual-identity prototype. It is not part of the
Astro site and shares no code with it. Everything lives in this folder.

> Work in progress — this README is completed in the final step of the build.

```bash
npm start        # build, then serve dist/ at http://localhost:4173
npm run dev      # serve src/ live, no build step
npm run build    # src/ + public/ -> dist/
npm run check    # contrast (all three accents), JS syntax, no external hosts
```

No `npm install` is needed: there are no dependencies. Node >= 20.

Specimen of the design system: `/system`.

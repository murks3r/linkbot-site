# Case-Study Templates (placeholders only — no invented results)

Status: **DRAFT — no case exists yet.** These templates are built so that the *first real pilot* can be written up without pressure to embellish. Rules: every number verified with the agency in writing; no candidate identities, ever; anonymized by default; approval artifact archived before any external use (`02-channels/referral-mechanism.md` §3).

---

## A. Agency pilot case study — [WORKING TITLE: "Ein Mandat, prüfbar: {agency-or-anonymized}" ]

**Metadata block (fill after pilot):**
```
Agency: [name | "eine Personalberatung im DACH-Raum" (anonymized)]
Discipline: [e.g., Data/Engineering]
Mandate: [one-liner; no client name without permission]
Pilot window: [dates]
Approval: [anonymized only | may name agency | may quote person (role only) | may share metrics: list]
Reviewed by agency on: [date]
```

**Structure:**

1. **Ausgangslage (2–3 sentences).** The agency's shortlist pain before the pilot, in *their* words if a quote is permitted: e.g., "[quote: what makes a shortlist defensible / where it breaks]". If no quote: paraphrase, marked as paraphrase.

2. **Was getestet wurde.** One mandate through: Brief → strukturierte Kriterien (hart vs. bevorzugt, offene Punkte sichtbar) → Abgleich mit dem **eigenen, autorisierten Pool der Agentur** → prüfbare Kurzliste → Recruiter-Entscheidung. Explicit non-claims: no ATS migration, no contact data touched, no network data, nothing sent.

3. **Was gemessen wurde (nur was tatsächlich gemessen wurde).**
   | Metric | Value | Who verified |
   |---|---|---|
   | Time to first shortlist draft | [measured value or "not measured — say so"] | agency + Linkbot |
   | Lines with attached evidence | [value] / [total] | |
   | Open UNKNOWNs surfaced (count) | [value] | |
   | Recruiter verdict on usefulness | [1 sentence, their words] | agency |
   | What did NOT work | [mandatory row — a case study without this row is marketing, not evidence] | |

4. **Was sich geändert hat (oder auch nicht).** Honest outcome statement. If the pilot did not change anything for them, the case study says so — and that becomes the *pilot that taught us*, not a hidden result. If second mandate happened: state it flatly ("Auf Basis des Tests führt die Agentur ein zweites Mandat durch") — never "sie sind begeistert".

5. **Grenzen des Falls.** "Ein Mandat, eine Agentur, kein Marktbeweis. Generiert keine Aussage über andere Pools." (This paragraph is not optional.)

6. **Call to action (agency audience):** "Der Ablauf ist als Ein-Mandat-Test buchbar, solange wir ihn mit 2–3 Agenturen pro Quartal begleiten können." + contact. `[Adjust to D1 decision; no price claims until decided]`

**Pre-publication checklist:**
- [ ] Agency approval artifact saved (metrics list explicit)
- [ ] Every number cross-checked against the pilot notes
- [ ] "What did not work" row present
- [ ] No person identifiable; no client named without consent
- [ ] Claims review (no superiority statements)
- [ ] DE + EN versions if both audiences get it (EN = method summary acceptable)

## B. Talent experience story — [WORKING TITLE: "So sucht {Vorname}, {Rolle}: privat, prüfbar, selbst entschieden"]

**Rules:** consent-based only; the person reviews the full text before publication; pseudonym allowed; no CV details beyond what they approve; if the story is negative, it can still be published with their consent (and should be, in the honest version).

**Structure:**

1. **Setup (their words allowed):** what their job search required; what they disliked about profile-first tools (if that's their story).
2. **What they did:** "Als Gast eine echte Suche gestartet" → "erklärtes Ergebnis verstanden (Grund, Fakten, UNKNOWN)" → "privat gespeichert / wieder gekommen" — only the steps that actually happened. If they quit at some step, the story is *about that*, honestly.
3. **What helped (concrete):** their sentence, not ours.
4. **What didn't:** their sentence, not ours.
5. **Whether/how they shared anything:** consent moments are the story's spine in this product.
6. **Limits box:** "Ein Mensch, ein Fall, kein Ergebnisversprechen."

**Internal use note:** until a real consented story exists, internal docs may reference the *synthetic* demo (`synthetic` label mandatory) — but nothing synthetic may ever be presented as a real person's story. One fake story would invalidate every honest one.

# Licensing and originality

Status: **reference, not legal advice.** Originality is a claim about provenance, and
provenance is checkable here because every outline is generated by a committed script.

---

## 1. The originality claim, and how to check it

**Claim: Linkbot Display, Linkbot Sans and Linkbot Mono are original works authored in
this repository. No glyph outline was copied, traced, imported or derived from any
existing typeface.**

The evidence is structural rather than a statement of intent:

1. **The outlines are generated, not drawn in an editor.** `scripts/glyphlib.py` expands
   centrelines into outlines by offsetting lines and elliptical arcs. Every contour in
   every binary is the output of that function. There is no artwork file to import.
2. **The input is a skeleton, not a source face.** `scripts/glyphset.py` defines each
   glyph as lines and arcs expressed in advance, sidebearing, x-height and stroke width.
   The unit of authorship is a centreline, and a centreline is not an outline.
3. **There is no third-party font in the pipeline.** The build reads the UFOs under
   `sources/ufo/`, which this repository writes from `glyphset.py` and
   `glyphset_extra.py`. No font binary is read as input anywhere in the build.
4. **The whole chain is in the repository.** `build_sources.py` →
   `build_fonts.py` → `validate_type.py`, standard-library Python plus the four declared
   build dependencies (fontTools, ufoLib2, ufo2ft, brotli), which are tools and not
   sources of outlines.

A reviewer can re-derive every binary from two Python files and compare hashes
(`validation/asset-registry.json`).

## 2. What the OFL does and does not cover here

The original faces are **not** OFL and do not need to be. OFL is the licence of the
fallback faces. Two distinct things are in this folder:

| | Original faces | Fallback faces |
| --- | --- | --- |
| Files | `fonts/ttf/*`, `fonts/woff2/*`, `sources/ufo/*` | none committed |
| Licence | project-owned original work | SIL OFL 1.1 |
| Obligation | none pending an owner decision on terms | licence text travels with the files if they are ever committed |

**Nothing in this folder is currently released under a licence.** The fonts are an
internal, non-applied prototype. Before any of them is published or shipped, the owner
must choose: release under the OFL, keep them proprietary, or commission terms from a
type designer. That choice is recorded as an open decision in `PROPOSED.md`, not assumed.

## 3. The fallback stack, and why it is behind the original faces

Declared in `../14-experiences/00-shared/fonts.css`:

| Role | Fallback | Licence | Self-hostable |
| --- | --- | --- | --- |
| Display | Iowan Old Style → Georgia → serif | system face, not redistributed | n/a |
| Sans | Inter | SIL OFL 1.1 | yes |
| Mono | JetBrains Mono | SIL OFL 1.1 | yes |

Both OFL faces were already verified in the Brand OS licence register
(`../../06-typography/licenses.md`) and require the licence text to travel with any
committed file. **No font files are committed in this folder**, so no licence text is
required yet. If the fallbacks are ever vendored, the obligations there apply unchanged:
commit `OFL.txt` beside each file, do not sell the fonts, and do not ship a subset under
the reserved name.

## 4. Trademark

The **mark** geometry is carried over unchanged from Brand OS Direction A; the
**wordmark** is new, because it is now outlined from Linkbot Display and its drawings did
not exist before. A trademark search on the previous concept file does not cover this
wordmark. Adopting it (decision **Y-04**) requires a fresh search in the relevant classes
and jurisdictions. This folder makes no trademark claim.

## 5. Third-party assets

None. There is no icon library, no bought font, no stock outline and no generated image in
this folder. The mark's octagon is arithmetic; the letters are centrelines; the specimen
page uses system-stack CSS and no external request.

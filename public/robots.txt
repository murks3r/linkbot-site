# robots.txt — the canonical host is resolved at build time (astro.config.mjs
# `site`, from SITE_ORIGIN / VERCEL_ENV / VERCEL_URL). See docs/preview/README.md
# and docs/site-hardening/.
#
# No `Sitemap:` directive is stored here on purpose: this is a static file, and a
# literal host would be wrong in every environment but one (and would cite a
# domain the organisation may not own). src/lib/preview-guard.mjs owns that
# directive instead: it appends `Sitemap: <build origin>/sitemap-index.xml` to
# the build output on an indexable build, and replaces the whole file with
# `Disallow: /` on every non-production build. Both directions are tested in
# tests/site-hardening/robots.test.mjs and tests/preview-smoke/output.test.mjs.

# Reserved paths: not part of the public site.
# `$` anchors the rule to the exact path, so a future public route such as
# /accessibility is not swallowed by an /access prefix rule.

Disallow: /jobs/

## What is open, what is hosted

**Open (meant to be, in this repository):** the contract copy these pages describe, the widget, the SDK and the framework adapters. The repository is private today and no licence is chosen: publication, domain and licence are the owner's decision.

**Hosted by Linkbot:** the space that answers the routes: its checks, private matching, the board, the introduction with both sides' yes, the history it builds up and billing. These pages describe how to talk to it; they do not contain it.

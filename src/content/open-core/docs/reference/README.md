# Reference

## What is open, what is hosted

**Open (in this repository):** the contract copy these pages describe, the widget, the SDK and the framework adapters. The code is licensed under Apache-2.0. The repository is private today.

**Hosted by Linkbot:** the space that answers the routes: its checks (today each side's email address; company checks are planned, not built), private matching, the board and the introduction with both sides' yes. The verified history and billing will be hosted too; both are planned, not built. These pages describe how to talk to the space; they do not contain it.
